Interview AI is an AI-powered web application that helps job seekers understand how well they match a specific job role and prepare for interviews more effectively.

Users can upload their resume, enter a job description, and get a personalized interview preparation report.

## ✨ Features

- 📄 Upload and analyze your resume
- 💼 Compare your profile with a job description
- 📊 Get a job match score
- ❓ Generate technical interview questions
- 🗣️ Generate behavioral interview questions
- 🎯 Identify missing skills and skill gaps
- 📚 Get a personalized preparation plan
- 🔐 User authentication
- 💾 Save and view previous interview reports

## 🛠️ Tech Stack

### Frontend
- React.js
- CSS
- JavaScript

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose

### AI Integration
- Google Gemini API

## 🚀 How It Works

1. Enter the job title and job description.
2. Upload your resume.
3. Add a short self-description.
4. Click **Generate Report**.
5. AI analyzes your profile and generates a personalized interview report.

## 🎯 Purpose

The goal of Interview AI is to make interview preparation more focused. Instead of preparing for random questions, users can understand their actual skill gaps and prepare specifically for the job they are applying for.

## 📦 Installation

Clone the repository:
```bash
git clone <your-repository-url>
```

Install dependencies:
```bash
npm install
```

Create a `.env` file and add the required environment variables:
```
MONGODB_URI=your_mongodb_connection_string
GEMINI_API_KEY=your_api_key
```

Start the development server:
```bash
npm run dev
```
